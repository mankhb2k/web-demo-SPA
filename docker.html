Docker Volume Lab

Mô phỏng sự bền vững của dữ liệu khi Container bị xóa (Phiên bản HTML/JS)

Quy trình vận hành

1. Code & Dockerfile

Chứa mã nguồn và chỉ dẫn build.

2. Docker Image

Bản đóng gói tĩnh, không đổi (Read-only).

3. Docker Compose

Định nghĩa cách gắn Volume vào Container.

4. Container (Runtime)

Tiến trình đang chạy. Có thể bị xóa bất cứ lúc nào.

CONTAINER
RUNNING
VOLUME: openclaw_data
Writing...
Trống (Đợi Container ghi dữ liệu)
System Output
Waiting for commands...

Giải thích Volume

  • 1. Ánh xạ (Mapping): Docker Compose nối thư mục /data/openclaw với Volume openclaw_data.
  • 2. Tính độc lập: Khi bạn nhấn Xóa Container, lớp Container mất nhưng Volume còn nguyên.
  • 3. Khôi phục: Khi chạy lại, Container mới sẽ tự tìm đến Volume cũ để lấy lại file JSON.

Bài tập thử nghiệm:

1. Build và Up Container.
2. Nhấn "Ghi dữ liệu" vài lần.
3. Nhấn "Xóa Container".
4. Nhấn "Up" lại và xem dữ liệu còn không!
