Web Demo SPA

Mẫu trang tĩnh đơn giản đã sẵn sàng để deploy lên GitHub Pages.

Thay nội dung trong file index.html bằng ứng dụng của bạn (HTML, CSS, JS). Nếu bạn dùng một SPA framework, build ra thư mục tĩnh rồi đặt file đầu ra tại đây.
